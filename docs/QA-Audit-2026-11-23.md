# QA Audit: Dima Hasao Android Apps — 23 Nov 2026

**Scope:** release APKs in `apps/` (User 1.0.4/code 6, Driver 1.0.3/code 4, Delivery 1.0.3/code 4, Restaurant 1.0.3/code 4) running against the **live production API** (`tourismdimahasao.in`).
**Device:** Android emulator, Pixel 6 profile (1080×2400, 420 dpi, Android 15 / API 35, 1.5–2 GB RAM, no GPU). Also tested at font scale 1.3 and display density 500 ("Large" display size).
**Test account:** the designated test phone (static OTP). No real customer, partner or admin account was used.
**Ground rules followed:** no code, config or data was changed. No order, booking, ride or partner account was created on production, because that would notify real partners or leave junk data. Anything that needed one is marked **BLOCKED**.

---

## 1. Summary

| Severity | Confirmed defects |
|---|---|
| Critical | 1 |
| High | 9 |
| Medium | 12 |
| Low | 13 |

**The three things that matter most before real users arrive:**
1. **Anyone can sign in as anyone (production).** The OTP endpoint accepts any 10 digits and returns the OTP in the response body, and the code is the static `1234`. This covers every app, including partner and admin logins.
2. **Production is full of test data that customers see.** Both "featured" restaurants are test kitchens with no menu, one 1,765 km away. 19 of the 20 tour coupons are named "QA business probe". Drivers can pick Indore and New Delhi as their city. Only "Bike" and "bike lite" exist as vehicle types.
3. **Several screens show success for things that never happen.** These include profile edit, the hotel invoice, the language switch and the member tier, plus hotel guest details and special requests that the server throws away.

### 2.1 Platform / Backend (affects all apps)

| ID | Sev | Defect | Steps / evidence | Expected | Actual | Business impact |

| B-03 | High | Room occupancy is not enforced | Quote for 20 adults in "Valley View Deluxe" (`maxAdults: 2`) returns ₹4,256, the same as for 2 adults | Error, an extra room, or an extra-adult charge | Same price. `extraAdults` is only applied if the client sends it | Revenue loss and over-occupancy disputes. |
| B-04 | Medium | Every resend resets the wrong-attempt counter | `otp.service.js` sets `existing.attempts = 0` on each request | The attempt cap holds across resends | Brute-force window grows by up to 3× per 10 minutes | Weakens OTP security once real SMS is on. |

## 4. Benchmark notes (MakeMyTrip / Booking.com, Ola / Rapido, Zomato / Swiggy)

- **Booking.com and MakeMyTrip** carry dates and guests from search into the room page, cap guests per room, and let you book for someone else. Hotels fail all three (U-04, B-03, B-02).
- **Ola and Rapido** show "No drivers nearby" instead of an ETA, and draw the route before booking (U-11).
- **Zomato and Swiggy** never list a restaurant without a menu or outside the delivery radius (D-01, D-02), and show an inline error on the field at fault, not a dead button (R-02).
- **All of them** enforce a 30 s resend cooldown and Indian mobile format checks (U-13, B-05, R-03).

## 6. Regression plan (after fixes)

Run on the same emulator at font 1.0 and at font 1.3 + display Large, and on one physical mid-range phone if available.

1. **Auth (all 4 apps):** valid, invalid (0-prefix, short, letters), wrong OTP, resend cooldown, session persistence after force-stop, logout.
2. **Legal links:** Privacy and Terms open before login in all apps, and Back returns to login with the typed phone kept.
3. **User profile:** edit name → reopen app → name persists, and the server returns the new name on `/food/auth/me`.
4. **Hotels:** list values carry to booking; stepper caps; 3 adults in a 2-adult room is rejected or priced; guest details visible in the partner app's booking detail.
5. **Packages:** 1 adult and 11 travellers are not possible; the price loads for 2–10.
6. **Unchanged flows to re-verify:** places, favourites, taxi fare quote, food browse, Razorpay sheet opens (test key), bookings tabs, offline banner.
7. **Isolated database run** (local mongod, see notes): one full food COD order, one taxi cash ride, one hotel and one package booking, to cover the flows marked BLOCKED here without touching production.
